# Tool Belt Unlimited

A Minecraft 1.21.1 NeoForge addon: configurable Tool Belt capacity (default: 20), Sewing Table upgrades, and optional `#c:tools` support.

Requires Tool Belt 2.2.9, Sewing Kit 2.0.9, and Kotlin for Forge 5.10+. Install on both client and server.

Configurable slots per row/ring, optional ring mode, visible-ring limit and cyclic wheel scrolling. Eye buttons hide individual rows from ring selection. Empty slots keep their positions; click, release-to-swap and cycle controls remain available.

Build: `./gradlew build`. [In-game UI validation](devtests/README.md).
