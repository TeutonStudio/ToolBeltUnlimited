# Tool Belt Unlimited

A Minecraft 1.21.1 NeoForge addon for Tool Belt: expand beyond nine slots (default maximum: 20), upgrade at the Sewing Table, and optionally allow all `#c:tools` items.

Requires Tool Belt 2.2.9, Sewing Kit 2.0.9, and Kotlin for Forge 5.10+. Install on both client and server.
